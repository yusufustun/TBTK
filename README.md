# TBTK - Transfer Books To Kindle
### Purpose
* Created this app in order to make transfering books to my kindle easier
* Useful if you don't have access to a cable


### How to Use
1. Must have Koreader (jailbroken kindle) set up
2. Set up SSH with kindle 
3. Launch TBTK and enter these details:
    - Host name of kindle (default is root)
    - IP address (ex: 198.163.0.53)
    - Path to ssh key in device (use ecdsa key)
    - Target directory (Select Koreader option)
    - Selection of files (books)
4. Click run!

#### More info
* Use **config.json** file so you don't have to re-type your details every time you launch the program
